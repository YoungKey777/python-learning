## ✅ 今天学了什么

- **复盘整理**：把 10 月以来的练习按「基本数据类型 → 数据结构 → NumPy → pandas」四层重新归档，脉络一下清楚了 —— 前面全是单值和小容器，从 NumPy 起才开始整块算数。
- **`np.array` 到底是什么类型**：`type()` 出来是 `numpy.ndarray`，是 numpy 库自己的类，不是 Python 内置类型；不 `import numpy` 就没有这个名字。
- **容器类型 vs 元素类型**：`ndarray` 是「装东西的盒子」，`dtype`（这里是 `float64`）是「里面装的东西」—— 一个数组里所有元素必须同 dtype，这正是它能整列运算的原因。
- **和 list / dict / set 的关系**：并列的四种容器，不是继承关系。可以互相转换（`np.array(列表)` 造数组，`.tolist()` 变回列表），但列表 `*2` 是复制，数组 `*2` 是每格翻倍 —— 这叫向量化。
- **没有 numpy 也能存数**：用列表或嵌套列表代替，功能不缺，缺的是向量化，得自己写循环。
- **008 课（LR / SVM / 决策树 / 随机森林）过了一遍**：线性回归从最小二乘推到正规方程 `(XᵀX)⁻¹Xᵀy`（求逆是 O(d³)，特征一多就顶不住）→ 梯度下降 / 随机梯度下降；SVM 走间隔 → 松弛变量 → 核技巧；决策树是 ID3 信息增益 → C4.5 增益率 → CART 基尼，再加剪枝；随机森林靠 bootstrap 抽样和袋外样本（约 37%）。

## ✅ 今天学了什么
- **8.1 语法错误 + 错误三分法**：语法错误（跑之前就报错/编译期拒稿/一句话错全文件连坐）、异常（跑起来才报错）、**逻辑错误 = 隐形第三类**（根本不报错，安静给你错答案——最阴险）；报错三件套（文件名+行号+箭头）是事故地图不是审判；**箭头 ≠ 修复点**；亲手触发 493 行全文件拒跑实况（连坐体感拉满）
- **8.2 traceback 阅读课**：**从下往上读**——最后一行判决书（类型+原因），往上事发经过；三兄弟混脸熟：ZeroDivisionError（分母可能为 0？）/ NameError（判决书点名缺谁，90% 是拼错）/ TypeError（小作文连修法都告诉你：str 不能拼 int，int('2')+2 或 '2'+str(2)）；3.11+ 的 ~^~ 精确圈出出事子表达式；**异常类型 = builtins 预装标识符**（和 print 住同屋，不用 import）
- **8.3 try/except（全章最值钱）**：安全网工作流（出错进匹配 except → 程序活着走完）；输入验证循环（break 放 try 里 = 成功才退出）；多 except = 分类保险（最多执行一张网）；**继承匹配 + 顺序陷阱**（except 从上往下找第一个能认领的，子类在前父类在后，调换顺序 B C D → B B B 亲自推演两遍）；异常家族树（KeyboardInterrupt 不是 Exception 子类 = 故意让 Ctrl+C 杀不死 try）；else 子句 = 没出错才走（避免误伤成功路径的异常）；异常穿透函数（网包调用点，不包函数内部）
- **8.4 raise 三形态**：带话抛 raise ValueError('话')（参数存 .args，纸条随便写——中文都行）；抛家族名 = 官方简写自动实例化；**裸 raise = 分层上报**（中间层接住→留痕→原样上交，案发现场 traceback 保留）
- **8.5 异常链**：except 里又出新异常 → 自动链上两段案卷（During handling...）；`raise 新 from exc` 显式声明因果（异常转换标配：底层细节 → 业务语言，保留根源）；`from None` 断链（旧的保密，只留真的问题）
- **深挖级追问（今天的隐藏收获）**：
  - class 最小前置：家族谱（class B(Exception) = 挂靠错误集团）、继承方向、`B()` 模具 vs 产品、引号 vs 名字（'B' 是文字，B 是模具——不引号就 NameError 或 str not callable）
  - 执行顺序逐行走查（for cls 三轮，raise 后 try 中断 → 分诊）
  - **raise 本身不打印任何东西！traceback 是异常逃逸没人管、程序临死前的解释器广播**
  - **traceback = 调用栈快照**（OS 知识落地！帧顺序 = 压栈顺序，栈顶 = 事故现场在最后，"most recent call last" 的来历）
  - except 认家族不认话（except 1 直接报错实验：网必须是 BaseException 家族出身）
  - return None 表示的失败 ≠ 异常，except 一概不管

## ✅ 今天干了什么

### pandas **Day 4 通关** —— 汇总统计（`groupby`）

一篇教程（[06_calculate_statistics](https://pandas.pydata.org/pandas-docs/version/2.3/getting_started/intro_tutorials/06_calculate_statistics.html)）。

**心智模型：拆开 → 算 → 拼回去。** 一句话概括就是「**按 ___ 分，算 ___**」。

### 1. 从「一个数」到「一堆数」

```python
print(df["Age"].mean())                      # 29.69911764705882 ← 一个数
print(df.groupby("Sex")["Age"].mean())       # 一堆数
```

```
Sex
female    27.915709
male      30.726645
Name: Age, dtype: float64
```

**「按什么分」的那个东西，分完就成了每行的门牌。** `Sex` 跑到左边去了。

跟 Day 2 的 `value_counts()` 对照，三处都不一样：

| | 门牌 | `Name:` | 顺序 |
|---|---|---|---|
| `value_counts()` | male / female | `count` | 按**数量**（577 > 314） |
| `groupby("Sex")` | female / male | `Age` | 按**字母序** |

`value_counts()` 只能数人头；`groupby` 想算什么算什么。

### 2. 拆开：`size()` vs `count()` —— 三个数全对上

```python
print(df.groupby("Sex")["Age"].size())     # 每堆几行
print(df.groupby("Sex")["Age"].count())    # 每堆有几个「有值」的
```

| | 女 | 男 | **合计** | 对上的是谁 |
|---|---|---|---|---|
| `size()` | 314 | 577 | **891** | Day 2 `value_counts()` |
| `count()` | 261 | 453 | **714** | Day 1 `info()` 的 `Age 714 non-null` |
| **差** | **53** | **124** | **177** | Day 1 `info()` 的「177 个洞」 |

**Day 1 只知道「有」177 个洞；今天知道「洞在哪」—— 女 53、男 124。**

### 3. 0/1 列的平均 = 比率

```python
print(df.groupby("Sex")["Survived"].mean())
# female 0.742038    male 0.188908
```

`Survived` 只有 0（没活）和 1（活了）—— 它的平均就是**活下来的比例**。

Day 3 那句「`True` 就是 1，`False` 就是 0」，在这儿结了果。

### 4. 多列分组：门牌分两层

```python
print(df.groupby(["Sex", "Pclass"])["Survived"].mean())
```

```
Sex     Pclass
female  1         0.968085
        2         0.921053
        3         0.500000
male    1         0.368852
        2         0.157407
        3         0.135447
Name: Survived, dtype: float64
```

- **方括号里给列表** —— 因为要按**两样**分
- **门牌两层**（叫 MultiIndex），`female` 只写一次，下面空着 = 「沿用上面的」
- **谁在外层，看列表里的先后**

**这张表真正值钱的地方：**

| | 只按性别 | 按性别 × 舱位 |
|---|---|---|
| **女性** | **0.742** | 头等 **0.968** ／ 二等 0.921 ／ 三等 **0.500** |
| **男性** | 0.189 | 头等 0.369 ／ 二等 0.157 ／ 三等 0.135 |

> **`0.742` 这个数，把 `0.968` 和 `0.500` 平均掉了。**
>
> 同样是女性，**头等舱和三等舱的生存率差了一倍**。只按性别分组，这个差别**根本看不见**。

而且 6 个分项按各自人数加权，能拼回那 2 个数 —— 跟 177 个洞是同一条道理。

## 🧠 今天攒下的两条

1. **分项加起来必须等于总数。** 对上了，说明你分对了 —— **这是最好的自检。**
2. **分组分得越细，被平均值掩盖的东西就越少。** `0.742` 里藏着的差别，拆到舱位才看得见。

## 🕳 坑

**① `.mean()` 默认跳过洞** —— `df["Age"].mean()` = 29.699 是 **714 个人**的平均，不是 891 个。参数叫 `skipna=True`，**跳过而且不告诉你**。

**② 「洞」这个主题，今天第三次出现：**

| 什么时候 | pandas 对洞做了什么 |
|---|---|
| Day 3 · `df["Age"] < 18` | 洞比出 `False`，**悄悄排除** |
| Day 3 · `value_counts()` | 洞**藏起来不显示** |
| Day 4 · `.mean()` | 洞**跳过不参与计算** |

> **规律：pandas 遇到洞的默认动作是「静悄悄跳过」。** 不报错、不警告、不提醒 —— 你得自己知道它在跳。

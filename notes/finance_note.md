#### 1. 股票是什么

**一句话：股票 = 公司的所有权份额（买了公司的一小块）。**

- **合伙开店类比**：和朋友开店各出 30% / 35% / 35% 的钱，赚了按股份分——上市公司就是把"店"切成上亿等份（每股），放交易所自由买卖
- **公司为什么发股票**：缺钱扩张又不想背债——发股票换钱**不用还**（代价：分所有权 + 分红）；发债券是借钱，**要还本付息**
- **风险定位**：风险资产，可能翻倍可能腰斩（公司破产 → 股份归零）；对比债券（借条，固定利息）——**股票搏高收益，债券求稳**
- 术语积累：Stock / Share / IPO（首次公开募股）

#### 2. 股票类型：普通股 vs 优先股

| | 普通股 Common | 优先股 Preferred |
|---|---|---|
| 分红 | **浮动**（赚多分多，不赚不分） | **固定**（约定金额，像利息） |
| 分红顺序 | 后（先分优先股） | **先**（"优先"的由来） |
| 投票权 | ✅ 有 | ❌ 通常没有 |
| 公司破产清算 | 排最后（债主>优先股>普通股） | 在普通股**之前** |
| 风险 | 高（弹性大） | 低（收益稳） |

- 本质：优先股 = **股票和债券的杂交体**（固定分红像债，清偿地位是股——**排债券后面**；债券利息必须付，优先股分红公司可拖欠）
- **优先股定价公式 P = D ÷ r**：D = 每年固定分红，r = 要求的回报率（例：分红 8 元，要求 10% → 股价 80 元；利率降 → 要求 8% → 股价 100 元）。**优先股价格跟着利率走**（和债券一个脾气）
- **面值 ≠ 市价**：面值 = 计算分红的基准（面值 100 × 股息率 8% = 每股分红 8 元，写死）；市价 = 实际成交价（P = D/r 决定）。**实际收益率 = 分红 ÷ 市价**（80 元买 → 10%；120 元买 → 6.7%）
- 量化视角：研究主体是普通股（高波动、有定价空间）；优先股流动性差，量化基本不碰；A 股优先股很少

#### 4. 股价怎么定

**股价公式（敲黑板）**：

```
每股价格 = 公司总价值（市值）÷ 股数
```

- 分子动、分母一般不动（除非增发/拆股）——公司价值翻倍 → 每股翻倍（例：市值 1000 万、股数 1000 万 → 1 元/股；市值 2000 万 → 2 元/股，手里股数不变）

**市值 vs 利润（新手最易混）**：

| | 是什么 | 例子 |
|---|---|---|
| 市值 | 公司现在**值多少钱** | 1000 万 |
| 利润 | 一年**赚了多少钱** | 一年赚 100 万 |

- 利润 ≠ 市值：赚的钱要么分红（按股份分），要么留在公司积累成资产
- 股价涨由**市场预期**驱动（未来能赚更多吗），不是 1:1 把利润换算成股价

**公司价值为什么涨**（赚钱传到股价的两条路）：
1. **预期驱动**：市场觉得未来更赚钱（新业务/行业景气）→ 抢着买 → 市值涨
2. **积累驱动**：利润留在公司变成资产（厂房/现金/专利）→ 净资产变厚 → 市值水涨船高

**为什么"买不完"（供需第一定律）**：
- 需求大 → **价格涨**（不是数量变多）；供给（股数）固定 → 数量不变
- 交易是**转让**：每一股都有主人，你要买必须有人卖；价格是**调节阀**——涨到有人获利了结、有人嫌贵不追，买卖重新平衡
- 类比：限量球鞋——大家抢 → 价格炒高，鞋不会变多也不会消失
- 特殊情况：真有人把愿意卖的股全收走 = **收购/私有化退市**（溢价收购，极少见）
- **成交量** = 当天实际换手的股数（有人卖才有人买）

#### 5. 怎么赚钱（股东总回报）

```
股东总回报 = 资本利得（差价）+ 股息（分红）
```

1. **差价**（资本利得 Capital Gain）：10 元买、15 元卖 → 赚 5 元（"做多"赚涨的钱）
2. **分红**（股息 Dividend）：公司盈利按股份分利润
- 不分红的公司（成长股）靠涨；分红的公司（价值股）靠现金——**能不能赚取决于公司价值是否真增长，与分红形式无关**
- "做多"= 先买后卖赚涨；"做空"= 先借后卖赚跌（交易机制章节展开）

#### 6. 分红与股息

- **分红 Dividend** = 公司赚钱后分给股东的钱（每股算：公司拿出 20 万 ÷ 10 万股 = 2 元/股）；一般一年一两次（年报/中报后）
- **市价 Market Price** = 买一股现在要花的钱（每秒钟都在变）
- **股息率 = 每股分红 ÷ 每股市价**（"股票的存款利率"）：
  - 票面股息率 = 分红 ÷ 面值（写死不变，优先股说明书上的）
  - 实际股息率 = 分红 ÷ 市价（市场说的都是这个，跟着股价变）
- **除息（分红后股价必然跌）**：分红 = 把公司现金搬到股东口袋 → 除息日股价**自动下调**分红金额（40 元 + 2 元分红 → 38 元 + 现金 2 元）；**总资产不变**（左口袋到右口袋，不是白赚）
- **分红的意义**（总资产不变为什么还分）：① 信号（能稳定分红 = 现金流真实、有信心）② 给需要现金流的投资者 ③ 市场偏好（红利策略）
- **成长股 vs 价值股**（一美元原则）：留存 1 美元利润若能创造 >1 美元市值 → 该留（成长股：不分红，靠资本利得）；创造不出 → 该分（价值股：分红，靠股息）。例子：早期亚马逊/特斯拉 vs 银行/公用事业
- **股息再投资 DRIP**：分红现金再买股 → 股数变多 → 复利滚雪球；A 股红利税：持股超 1 年免税、1 个月~1 年 10%、1 个月内 20%
- 量化预告：除息造成价格跳空 → 算收益率前必须**复权**（前/后复权）——量化第一坑

#### 7. 估值指标

- **市盈率 P/E = 市值 ÷ 年利润**：衡量"贵不贵"（1000 万市值、100 万年利润 → P/E=10 ≈ 10 年回本）
- **低 P/E = 便宜 = 价值因子雏形**（量化选股核心指标）；以后学 P/B 市净率、股息率，一起构成价值因子
- **优先股定价 P = D ÷ r**（见第 2 节）——"贴现"思想的雏形，收益与定价章节正式学

#### 8. 股东权利与公司治理

- **一股一票**：普通股有投票权，公司大事（分红、并购、董事会）股东大会表决
- **分红决策权**：董事会提案 → 股东大会投票；小股东票少说了不算，只能"**用脚投票**"（卖股走人）
- **优先股无投票权**（只拿固定分红）
- **技术入股** = 用技术（专利/软件著作权）**评估作价**换股份，流程：评估 → 折出资 → 权利过户给公司
  - 例：A 现金 100 万、B 现金 100 万、C 技术作价 50 万 → 总盘子 250 万，C 占 20%
  - 与现金入股：占股分红一样，但要办**权利转移登记**（专利过户），风险是**技术会过时**（评估虚高是打假重点）
  - 科研意义 🎯：博士的算法/专利将来创业 = 技术入股的本钱（产学研转化标配：教授出技术、投资人出钱）

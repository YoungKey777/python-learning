## 1. 投资工具

### 证券 Securities（先认识伞）

**一句话：证券 = 把"权利"写成的凭证（证书）——代表权利、有价值、可转让买卖。** "证" = 证明（你拥有某个权利）。
**为什么叫"有价"**：凭证本身不值钱（一张纸几毛钱），值钱的是它代表的**权利**（股票凭证背后是茅台 100 股所有权 = 15 万）——像电影票：纸不值钱，值钱的是"进场看电影的权利"。

**证券的伞结构（按权利分类）**：

| 大类 | 代表什么权利 | 例子 | 备注 |
|---|---|---|---|
| **资本证券** | 投资/所有权/债权 | **股票、债券**、ETF/基金 | 💰 金融和量化的主角 |
| 货币证券 | 代替钱付款 | 支票、汇票 | 老玩法，了解即可 |
| 商品证券 | 一批货的归属 | 提货单、仓单 | 拿了单子提货 |

- 金融文档里的"证券""标的" ≈ 资本证券，即**交易对象本身**（股票/期货/期权/ETF 都是）
- 伞下家族：**股票** = 所有权凭证（老板之一）；**债券** = 债权凭证（债主）；**ETF** = 一篮子资产的份额凭证——区别只是凭证背后写的权利不同
- 量化视角：量化 = 在证券市场上用程序找定价错误；学过的 dict/list 就是为处理证券数据服务的
- 术语积累：Securities（证券）；《投资学》第 2 章"资产类别与金融工具"系统讲证券分类（第一个正式框架）

#### 1. 股票是什么

**一句话：股票 = 公司的所有权份额（买了公司的一小块）。**

- **合伙开店类比**：和朋友开店各出 30% / 35% / 35% 的钱，赚了按股份分——上市公司就是把"店"切成上亿等份（每股），放交易所自由买卖
- **公司为什么发股票**：缺钱扩张又不想背债——发股票换钱**不用还**（代价：分所有权 + 分红）；发债券是借钱，**要还本付息**
- **风险定位**：风险资产，可能翻倍可能腰斩（公司破产 → 股份归零）；对比债券（借条，固定利息）——**股票搏高收益，债券求稳**
- 术语积累：Stock / Share / IPO（首次公开募股）

#### 2. 股票类型：普通股 vs 优先股

| | 普通股 Common | 优先股 Preferred |
|---|---|---|
| 分红 | **浮动**（赚多分多，不赚不分） | **固定**（约定金额，像利息） |
| 分红顺序 | 后（先分优先股） | **先**（"优先"的由来） |
| 投票权 | ✅ 有 | ❌ 通常没有 |
| 公司破产清算 | 排最后（债主>优先股>普通股） | 在普通股**之前** |
| 风险 | 高（弹性大） | 低（收益稳） |

- 本质：优先股 = **股票和债券的杂交体**（固定分红像债，清偿地位是股——**排债券后面**；债券利息必须付，优先股分红公司可拖欠）
- **优先股定价公式 P = D ÷ r**：D = 每年固定分红，r = 要求的回报率（例：分红 8 元，要求 10% → 股价 80 元；利率降 → 要求 8% → 股价 100 元）。**优先股价格跟着利率走**（和债券一个脾气）
- **面值 ≠ 市价**：面值 = 计算分红的基准（面值 100 × 股息率 8% = 每股分红 8 元，写死）；市价 = 实际成交价（P = D/r 决定）。**实际收益率 = 分红 ÷ 市价**（80 元买 → 10%；120 元买 → 6.7%）
- 量化视角：研究主体是普通股（高波动、有定价空间）；优先股流动性差，量化基本不碰；A 股优先股很少

**B 股（历史产物：外币"侧门"，名存实亡）**：

**为什么腾讯/B 站这些巨头不在 A 股上市（三个历史门坎）**：
- **门坎 1：A 股要求连续盈利三年**——互联网公司"先烧钱圈地后赚钱"（B 站亏十几年），报名资格都没有；美股/港股不要求盈利
- **门坎 2：外资限制 → VIE 架构**：互联网/增值电信业务不允许外资控股，但早期靠美元基金 → 只能注册在开曼（法律上是"外资公司"），靠协议控制境内实体 = **VIE 架构**；A 股不认这种结构，拆 VIE 回 A 成本巨大（买回外资+重组+补税，耗时两三年）
- **门坎 3：同股同权 vs AB 股**：创始人要一票顶 20 票（AB 股），A 股老规矩一人一票（2019 科创板才放开）；港交所 2018 改革、美股一直允许

- 量化视角：中国最赚钱的互联网公司大部分在港/美 → 量化主战场"**A 股 > 港股 > 美股（中概）**"排序的含金量就在这
- 术语积累：VIE（可变利益实体）、红筹（注册境外、业务境内）、二次上市

#### 4. 股价怎么定

**股价公式（敲黑板）**：

```
每股价格 = 公司总价值（市值）÷ 股数
```

- 分子动、分母一般不动（除非增发/拆股）——公司价值翻倍 → 每股翻倍（例：市值 1000 万、股数 1000 万 → 1 元/股；市值 2000 万 → 2 元/股，手里股数不变）

**市值 vs 利润（新手最易混）**：

| | 是什么 | 例子 |
|---|---|---|
| 市值 | 公司现在**值多少钱** | 1000 万 |
| 利润 | 一年**赚了多少钱** | 一年赚 100 万 |

- 利润 ≠ 市值：赚的钱要么分红（按股份分），要么留在公司积累成资产
- 股价涨由**市场预期**驱动（未来能赚更多吗），不是 1:1 把利润换算成股价

**公司价值为什么涨**（赚钱传到股价的两条路）：
1. **预期驱动**：市场觉得未来更赚钱（新业务/行业景气）→ 抢着买 → 市值涨
2. **积累驱动**：利润留在公司变成资产（厂房/现金/专利）→ 净资产变厚 → 市值水涨船高

**为什么"买不完"（供需第一定律）**：
- 需求大 → **价格涨**（不是数量变多）；供给（股数）固定 → 数量不变
- 交易是**转让**：每一股都有主人，你要买必须有人卖；价格是**调节阀**——涨到有人获利了结、有人嫌贵不追，买卖重新平衡
- 类比：限量球鞋——大家抢 → 价格炒高，鞋不会变多也不会消失
- 特殊情况：真有人把愿意卖的股全收走 = **收购/私有化退市**（溢价收购，极少见）
- **成交量** = 当天实际换手的股数（有人卖才有人买）

#### 5. 怎么赚钱（股东总回报）

```
股东总回报 = 资本利得（差价）+ 股息（分红）
```

1. **差价**（资本利得 Capital Gain）：10 元买、15 元卖 → 赚 5 元（"做多"赚涨的钱）
2. **分红**（股息 Dividend）：公司盈利按股份分利润
- 不分红的公司（成长股）靠涨；分红的公司（价值股）靠现金——**能不能赚取决于公司价值是否真增长，与分红形式无关**
- "做多"= 先买后卖赚涨；"做空"= 先借后卖赚跌（交易机制章节展开）

#### 6. 分红与股息

- **分红 Dividend** = 公司赚钱后分给股东的钱（每股算：公司拿出 20 万 ÷ 10 万股 = 2 元/股）；一般一年一两次（年报/中报后）
- **市价 Market Price** = 买一股现在要花的钱（每秒钟都在变）
- **股息率 = 每股分红 ÷ 每股市价**（"股票的存款利率"）：
  - 票面股息率 = 分红 ÷ 面值（写死不变，优先股说明书上的）
  - 实际股息率 = 分红 ÷ 市价（市场说的都是这个，跟着股价变）
- **除息（分红后股价必然跌）**：分红 = 把公司现金搬到股东口袋 → 除息日股价**自动下调**分红金额（40 元 + 2 元分红 → 38 元 + 现金 2 元）；**总资产不变**（左口袋到右口袋，不是白赚）
- **分红的意义**（总资产不变为什么还分）：① 信号（能稳定分红 = 现金流真实、有信心）② 给需要现金流的投资者 ③ 市场偏好（红利策略）
- **成长股 vs 价值股**（一美元原则）：留存 1 美元利润若能创造 >1 美元市值 → 该留（成长股：不分红，靠资本利得）；创造不出 → 该分（价值股：分红，靠股息）。例子：早期亚马逊/特斯拉 vs 银行/公用事业
- **股息再投资 DRIP**：分红现金再买股 → 股数变多 → 复利滚雪球；A 股红利税：持股超 1 年免税、1 个月~1 年 10%、1 个月内 20%
- 量化预告：除息造成价格跳空 → 算收益率前必须**复权**（前/后复权）——量化第一坑

#### 7. 估值指标

- **市盈率 P/E = 市值 ÷ 年利润**：衡量"贵不贵"（1000 万市值、100 万年利润 → P/E=10 ≈ 10 年回本）
- **低 P/E = 便宜 = 价值因子雏形**（量化选股核心指标）；以后学 P/B 市净率、股息率，一起构成价值因子
- **优先股定价 P = D ÷ r**（见第 2 节）——"贴现"思想的雏形，收益与定价章节正式学

#### 8. 股东权利与公司治理

- **一股一票**：普通股有投票权，公司大事（分红、并购、董事会）股东大会表决
- **分红决策权**：董事会提案 → 股东大会投票；小股东票少说了不算，只能"**用脚投票**"（卖股走人）
- **优先股无投票权**（只拿固定分红）
- **技术入股** = 用技术（专利/软件著作权）**评估作价**换股份，流程：评估 → 折出资 → 权利过户给公司
  - 例：A 现金 100 万、B 现金 100 万、C 技术作价 50 万 → 总盘子 250 万，C 占 20%
  - 与现金入股：占股分红一样，但要办**权利转移登记**（专利过户），风险是**技术会过时**（评估虚高是打假重点）
  - 科研意义 🎯：博士的算法/专利将来创业 = 技术入股的本钱（产学研转化标配：教授出技术、投资人出钱）

#### 9. 怎么交易（一天的时间轴）

**A 股一天的交易分两段**：

```
9:15───9:20───9:25          9:30───────11:30  13:00───────15:00
│ 可挂可撤 │ 只能挂不能撤 │      连续竞价（实时买卖）
│←── 集合竞价 ──→│
     9:25 出开盘价          （深市收盘前 14:57-15:00 也有集合竞价）
```

**① 挂单**：把"买/卖多少股、什么价"报给交易所，先挂着等对手
- 盘口软件上的"买一/卖一/买二…" = 当前挂着的单子（订单簿）
- 挂单上限价 = **限价单**：咬死价格（贵了不买、便宜了不卖）

**② 撤单**：单子没成交前取消它（改主意/改价/等更好的价）
- ⚠️ 虚假申报：挂巨单吓人、快成交前撤掉——监管重点打击

**③ 集合竞价（开盘价怎么定）**：9:15-9:25 只挂单不成交，9:25 一次性撮合
- **撮合原则 = 找一个"成交量最大"的价**（喊高了没人买、喊低了卖家不卖，取平衡点），全场统一按这个价成交
- 9:20 后**不能撤单**：防止挂假大单把开盘价顶起来再撤（骗炮）

**④ 连续竞价（日常交易）**：9:30 后实时撮合，两条铁规则
1. **价格优先**：买方出价高者先成交、卖方出价低者先成交
2. **时间优先**：同价位先挂单者先成交（先来后到）
- 类比：集合竞价 = 双选会统一配对；连续竞价 = 菜市场实时讨价还价

**⑤ 开盘价 = 集合竞价的产物**（今天第一笔成交价；隔夜信息的集中定价）
- **锚是昨天收盘价**：开盘价只能在昨收 ±10%（主板）笼子里
- 高开/低开/跳空 = 开盘价明显高于/低于/越过昨收一大截 → 隔夜有消息、情绪剧烈
- 看盘第一件事：今开 vs 昨收

**⑥ 价格家族 OHLC（量化日线数据的四个价，以后拉数据天天见）**：
- O = Open 开盘价（9:25 集合竞价产物）/ H = High 最高价 / L = Low 最低价 / C = Close 收盘价（深市 15:00 集合竞价产物）
- 一根 K 线 = 四个价画的（红绿蜡烛图）

**数量规则（尺子：一手 = 100 股）**：
- **买入必须 100 股（1 手）的整数倍**：100/200/300……不能买 150 股（废单）
- **卖出例外（零股规则）**：零股（送股/配股产生的不足 100 股，如 10 送 3 → 100 股变 130 股）**必须一次性全卖**，不能拆着卖
- 三所对比：主板/创业板 = 100 股整数倍；科创板（688）= **200 股起**、之后可 1 股递增（201/202…）；北交所 = 100 股起可 1 股递增——零股都须一次性卖出
- 港股对照：1 手多少股**公司自定**（腾讯 100 股、汇丰 400 股）；美股：没有"手"，1 股起买还支持碎股
- **现实意义 = 资金门槛**：一手茅台 = 100 × 1500 = 15 万 → 小资金够不着高价股，所以有人买 ETF（几百块上车）
- 价格最小档位：A 股报价最小变动 **0.01 元**（10.00 → 10.01，不能报 10.005）
- 量化 💰：**回测下单必须 100 股整数倍取整**（`数量 = (数量 // 100) * 100`）——按 367 股下单 A 股根本成交不了，回测就是假的

**量化相关 💰**：**信号收盘后计算、次日开盘价成交**——回测标准假设（收盘才算完信号，最快明天开盘买）；回测框架里 `data['open']` 就是干这个的

**市场黑话（游资圈行话，听得懂就行，别急着参与）**：
- **冲天炮 🚀**：竞价/开盘瞬间暴力买盘把价格打上天（分时一根线直冲）——资金抢筹心切（"不让低位捡到，直接高价扫"）
- **核按钮 💣**：竞价/开盘瞬间巨量卖盘把价格炸下去（甚至一字跌停）——资金不计成本夺路而逃
- 一对镜像：冲天炮 = 极度贪婪/向上抢筹；核按钮 = 极度恐慌/向下砸盘；都在开盘几分钟定生死
- **反杀剧情**：昨天冲天炮今天核按钮——情绪反转极快，追高散户两头挨打
- 语境：超短线（打板/龙头战法）赌短期情绪，看股吧/游资复盘需要翻译器；价值投资用不上
- 量化 💰：情绪极端**可被程序化捕捉**（竞价涨幅 >5% 清单、开盘 1 分钟跌幅 >3%）——但量化优势是**不赌情绪**，把情绪当数据统计（冲天炮后接核按钮概率可回测）

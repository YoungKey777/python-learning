## Day 1 · ndarray 是什么

> **一句话**：pandas 的 Series 和 DataFrame **底下就是一根 numpy 数组** —— `.shape` / `.dtype` / `.ndim` 都是从 numpy 借来的，`.to_numpy()` 就是把外面那层标签皮扒掉。

**3 个关键操作**

| 操作 | 干什么 |
|---|---|
| `np.array(nums)` | 从 list 造数组。同一个 `*`：list 是**复制**（3 个数变 6 个），数组是**逐元素**（每个各自 ×2） |
| `a.shape` / `a.dtype` / `a.ndim` | 形状 / 类型 / 维度数。打印出来**括号几层就是几维**；`ndim` = shape 里有几个数 |
| `df["Age"].to_numpy()`、`df.to_numpy()` | 脱壳。一列脱出来是 `(891,)` float64；整表压成一根是 `(891, 12)` object |

**踩的坑**

- `(3,)` 里那个逗号不是排版，是**元组语法**（`(3)` 在 Python 眼里就是普通括号里装了个 3）
- 整表 `to_numpy()` 会**降级成 `object`** —— 因为 DataFrame 是「**一列一根数组**并排放」，压成一根时不同列挤不进同一种类型，只能全体降级
- 判别招：`list` 有逗号 `[1.2, 3.4, 5.6]`，`array` 用空格隔开并对齐 `[ 2.4  6.8 11.2]`

## Day 2 · 索引切片

> **一句话**：方括号里**逗号前挑行、逗号后挑列**，范围**含头不含尾**；往里塞一张真假表当筛子时，挑「格子」还是挑「整行」由**筛子的形状**决定。

**3 个关键操作**

| 操作 | 干什么 |
|---|---|
| `t[:, 0]` / `t[0, 0]` | `:` 单独站 = 这一维**全都要**；逗号隔开两个数 = 直接**点到一格**（`t[0, 0]` 得到一个数，不是一根线） |
| `t[0:2, 1:3]` | 范围切片：行 0~1 × 列 1~2 的一块。**尾巴 − 头 = 拿到几个**（2 − 0 = 2） |
| `t[t > 5]` / `s[s > 30]` / `df[df["Age"] > 30]` | **布尔索引**：比较运算符是**逐元素**的，先比出一张真假表，再拿它当筛子 |

**踩的坑**

- **含头不含尾**：`0:2` 给的是编号 0、1，**不含 2**
- **筛子的形状决定挑什么**：跟被筛的东西**同形**（`t > 5`，9 个答案，一格一个）→ 挑**格子** → 结果**压平成一维**，位置信息丢掉；**少一维**（`t[:, 0] > 4`，3 个答案，一行一个）→ 挑**整行**，整行原样搬走（`[[9 1 1]]` 里那两个 `1` 根本没参与比较，却跟着走了）
- `df[mask]` 和 `a[mask]` 是**同一件事**：拿一根线当筛子挑整行。区别只在 pandas 还留着其他列和行号 —— `df[df["Age"] > 30].shape` 是 `(305, 12)`，`s[s > 30].shape` 是 `(305,)`，**行数同为 305**
- 打代码要用**英文半角冒号** `:`，输入法中文状态的全角 `：` 会直接 SyntaxError

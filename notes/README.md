# 📚 学习笔记

按主题放，每个主题一个文件夹或一个 md：

```
notes/
├── 01-基础语法.md      # 阶段 1
├── 02-numpy-pandas.md  # 阶段 2
├── 03-可视化.md        # 阶段 3
├── 04-机器学习.md      # 阶段 4
├── 05-时间序列.md      # 阶段 5
└── 06-项目笔记.md      # 阶段 6
```

**写笔记的原则**：
- 用自己的话写，能讲给别人听才算懂
- 每篇开头写"这篇笔记解决什么问题"
- 代码示例要能直接跑
- 可以用 Obsidian 打开本仓库文件夹管理（支持双向链接）

# 量化金融基础课笔记

> 来源：001.基础课程1：量化金融基础.docx · 总结于 2026-10-07 · 原文 42071 字符

## 一、这份文档在解决什么问题

- **听众的金融基础几乎为零**：课堂调查显示，听众以计算机、数学、统计等理工科背景为主，学金融的很少，相当一部分人完全没有接触过金融。
- **要做量化，先得知道自己在哪个市场、跟谁打交道**：课程要把金融体系的骨架先搭起来——交易发生在哪一层、成本怎么算、有哪些标的和机构，才谈得上写策略。
- **内容取舍以"量化用不用得上"为准**：讲师把课件分成两部分，一部分详细讲（量化从业者也必须懂），一部分略过（非量化方向才需要）。预习作业里要求查的名词属于必须掌握的那一类。
- **"金融能否被量化"本身有争议**：很多人因为金融市场噪音太多，不认为它可以量化。讲师的观点是噪音多不等于不能量化，业界多年摸索已经积累出不少方法。

## 二、核心结论

- **量化交易几乎只发生在二级市场**：一级市场是公司首次发股发债拿钱的地方，有资格门槛，量化与之无关；二级市场是已发行证券在投资者之间转手，量化策略在这里找上涨标的、买低卖高。
- **佣金、手续费和滑点是量化的生死线**：成本变高策略就难做，成本变低或交易所返佣策略就好做。加密货币和期货市场的高频交易更活跃，与这一点直接相关。
- **A股的规则让传统因子失效更快**：T+1、涨跌停、缺少做空渠道等限制下，很多基本面因子只能当参考；讲师提到不少从业者因此转向高频方向。
- **风险无法消除，风险本身就是最大的阿尔法**：讲师反复强调不能拒绝风险，也不能不敬畏风险。风险管理是量化交易成功的关键，量化比主观交易占优的地方之一就是更理性地控制风险和情绪。
- **因子的边际收益高于模型**：因子足够好时模型不必复杂；因子不好时复杂模型很难救，还可能反过来把好因子搞坏。

## 三、金融市场与交易机制

### 1. 量化真正交易的场所是二级市场

- **一级市场**：公司第一次把股票、债券卖给公众，买这些新证券相当于给公司提供资金。不是谁都能买，买家要过资格审查，券商承销时也不直接面向普通投资者，IPO 就发生在这一层。
- **二级市场**：已经发行出去的股票、债券在交易所或场外买卖，钱在投资者之间流转，不再进入公司账户。量化交易全部在这一层完成。
- **市值算法**：已发行证券在二级市场的价格乘以全部股权，就是粗略的市值。
- **PE/VC（私募股权与风险投资）**：在一级市场买非上市公司股权的投资机构。讲师提到这两年很难做，原因指向美元加息和国际市场资金流动。
- **上市公司与否的实际区别**：公司再好，只要没上市（如字节跳动、华为），量化交易者也买不到它的股票。

### 2. 交易机制主要是撮合、竞价和做市

- **订单簿撮合**：买卖双方各自提交订单，价格匹配上交易就成立。
- **市场撮合**：交易所出面帮双方撮合。例如一方挂 10.01、另一方挂 10.02，差一点成交不了，交易所会介入。
- **竞价交易**：双方提交委托并报价。A股开盘前 15 分钟是集合竞价时段。
- **做市商**：专门买进再卖出（或卖出再买进）来提供流动性。市场上只靠普通买卖双方时，冷门公司容易出现想买买不到的情况；做市商在流动性稀缺时释放流动性，赚取买卖差价。个人也可以做这件事，不一定要牌照。
- **金融市场的作用**：资源配置、价格发现、传递信息（被称为经济晴雨表）、风险管理。讲师的观点是股市不涨也不该关掉，而应想办法解决它背后的问题。

### 3. 交易者和中介各有分工

- **个人投资者**：普通交易者。
- **机构交易者**：私募基金、公募基金、证券自营、对冲基金等，也是量化从业者以后要去的地方。
- **公司和企业**：主要是来融资的，不是来交易的。
- **做市商**：专业交易者。
- **中介与政府**：证券交易所、期货交易所、银行、证券公司、期货公司主要做中介，不自营就不参与交易，但中介本身也能赚很多；政府主要是融资，也可能下场救市。

## 四、交易成本、流动性与行情数据

### 1. 成本与滑点决定策略能不能活

- **佣金与手续费**：交易时付给经纪人或交易平台的钱，A股还有印花税。成本升高量化就难做，成本降低或交易所返佣量化就好做。
- **返佣的例子**：加密货币交易所为吸引交易量，会给高频交易者返佣，做一笔交易不但不付钱、还能拿钱。讲师认为这是前两年一些高频量化在加密货币上赚到很多钱的原因之一。
- **期货手续费低于股票**：原文提到期货手续费非常低，A股股票手续费偏高，后来有所下降。
- **滑点**：下单时看到的价格和实际成交价的差额。例如看到 10 元，指令传过去已变成 10.01 元，这 0.01 元就是滑点。
- **低价股对量化不友好**：港股有一两块钱的股票，如果最小价格变动单位是 0.01 或 0.001，一次滑点就相当于价格的千分之一甚至百分之一。量化公司因此偏好高价股，高价股的滑点通常只有万分之几。

### 2. 订单簿与 K 线提供的不是同一类信息

- **订单簿（order book）**：实时显示不同价格上的买单和卖单各有多少，反映当前挂单状况和能否成交。
- **K 线**：显示一段时间内的开盘价、收盘价、最高价、最低价，每一分钟甚至每一秒的价格都算一根 K 线，本质是历史价格走势。
- **层级差异**：订单簿是微观层面的实时数据，K 线是把订单簿价格拟合后的、相对宏观的结果。
- **数据量差异**：基于订单簿的策略每个 tick 都有大量数据，一天下来数据量很大；基于 K 线则数据有限。A股一天只交易 4 小时（9:30–11:30、13:00–15:00），按分钟算一天只有 240 条数据。
- **流动性判断**：订单簿稀疏说明流动性差，策略难做；订单簿稠密、交易量大时，高频策略更容易成功。
- **订单侵略性**：挂单的激进程度，买价越接近或超过当前价格越激进，说明越迫切想成交。整个订单簿可以反映所有买方和卖方的整体激进程度，据此可以构造一系列因子。讲师强调要用动态眼光看订单簿，不能静态地看。

### 3. 成交量既影响市场也影响模型

- **市场层面**：成交量反映市场活跃程度。成交量大意味着交易者多、流动性高、价格波动大，价格趋势也更可靠。
- **量化层面**：成交量大时容易找到对手方，滑点和交易成本低；低成交量下这两项都会恶化。
- **模型可靠性**：高成交量时模型预测更可靠；低成交量时信号中的噪音增加，个别交易者的大额买卖容易让模型过拟合。
- **课堂当天的数据**：A股当天成交量为 7050 亿。

## 五、常见的金融工具与标的

### 1. 美国十年期国债利率是全球市场的定价基准

- **性质**：美国十年期国债被视为风险较低的投资选择，比股票和其他债券安全得多。
- **影响机制**：它的利率上升会挤压其他金融工具的空间，因为资金会流向这种低风险资产，其他资产价格承压。讲师提到最近 A股和美股下跌，与十年期国债利率创新高有关。
- **从业者习惯**：讲师提到做传统金融或一些特定交易的人，早上起来会先看当天的美国十年期国债利率。原文中这类交易的名称转写为"cl 3 trading"，具体所指无法辨认。

### 2. 可转债兼有债券和期权两种属性

- **转换机制**：持有人可以在特定条件下把债券转成公司股票，也可能被强制转股，兼具债务和股权两种特征。
- **定价与溢价**：A股新发行的可转债标准标价是 100 元，讲师说上市第一天一般会涨破 110 元。公司因为给了转股的可能性，不会给很高的债券利率，所以可转债利率较低、溢价较高。
- **价格与正股的关系**：可转债价格与股票价格联系紧密。股票涨得少时债券涨得多；股票涨得多时，直接买股票或转股比持有可转债更有吸引力。
- **常见策略**：事件驱动（公司发布重大信息时可转债价格可能剧烈波动，可当 CTA 用）、可转债与正股之间的价差套利，以及利用期权性质做蒙特卡罗模拟来模拟价差。
- **定价模型**：讲师提到一种常见的可转债模型是把期权定价的 BS model 用到可转债上，同时考虑债券和权益两方面。做这类模型需要公司提供算力，否则一次回测要跑几天。
- **课程覆盖**：讲师明确说正课不涉及可转债，但可能后续会考虑开课。

### 3. 期货的核心是杠杆

- **合约性质**：期货是标准化协议，约定在未来某个时间以特定价格交割一定数量的标的资产，标的可以是商品、货币或股票。分商品期货和金融期货。
- **交易术语**：买方即多头（做多），卖方即空头（做空），还有开仓、平仓、杠杆。
- **保证金与爆仓**：交易期货只需交保证金，大约 5% 到 10%。按 5% 算，杠杆可以到 20 倍，价格下跌 5% 就会爆仓。交易所会在保证金不足时打电话要求补保证金，不补就强制平仓；讲师形容这是期货交易者最怕接到的一类电话。
- **永续期货**：比特币期货是永续的，没有到期日，可以一直持有。
- **期货量化的特点**：品种少（A股有 5000 多只股票，期货只有几十种），可用样本有限，容易过拟合，所以期货更适合做高频。品种之间流动性差异巨大：铜、原油流动性大，生猪、棉花、豆粕不一定随时都好，流动性差会推高滑点。任何期货策略都上杠杆，所以最大回撤数据很重要，不能爆仓。
- **另类数据**：期货领域有公司用无人机勘测原油，属于典型的另类数据。
- **国债期货**：标的是债，同时又是期货，可以做期现货套利。期货最终会交割，现货与期货的价差在未来某个时间点会归零；理论上可以坚定持有等价差收敛，但时间成本很高，可能到归零时也没赚到钱。

### 4. 加密货币在高频交易上有独特条件

- **基本面之争**：讲师在饭桌上和人讨论过比特币有没有基本面。腾讯的基本面是财报、现金流和稳定赚钱的游戏业务；可口可乐的基本面是全世界都喝、有天然垄断性。讲师认为比特币从某种角度看也有基本面，因为加密货币具备匿名、安全的交易属性，确实有很多人需要用，但具体为什么需要用很难说清。
- **匿名性用途**：加密货币去中心化、交易不留痕迹，很多人用它洗钱。讲师提到曾考虑让学生用加密货币交课程费用，后来觉得像诈骗而放弃。
- **7×24 小时交易**：加密货币市场不休息，随时可以做，这是高频交易有意思的原因之一。
- **数据开放**：大部分交易数据公开可见，高频数据比股票容易获得，方便回测和模型开发。
- **波动性**：加密货币波动很大，讲师提到自己回测时见过一天之内涨跌百分之几十的情况。
- **以太坊**：与比特币类似，但影响力没有比特币大。

## 六、宏观经济指标与汇率

### 1. CPI 是美联储加息降息的主要依据

- **CPI（消费者物价指数）**：用来衡量通胀水平。数值高说明通胀高，美联储倾向加息；数值低则可能转向宽松。鹰派和鸽派的切换主要看 CPI 和核心 CPI。
- **为什么要压低 CPI**：CPI 高会侵蚀实际收入。这个月领一万块工资，下个月同样一万块买不到原来那么多东西，相当于工资在缩水，容易引发不满，政府必须处理。
- **CPI 太低也不行**：如果 CPI 是负数就是通缩，物价不涨反跌，社会信贷水平和经济繁荣程度会下降。一般认为温和区间在 1% 到 2%，或到 3% 左右。
- **核心 CPI**：剔除食品和能源，因为这两项波动大，尤其油价。核心 CPI 更能反映通胀的基本趋势。

### 2. 其余宏观指标大多是判断经济冷热的温度计

- **GDP（国内生产总值）**：一个国家或地区所有商品和服务市场价值的总和，衡量经济总体规模。原文提到有两种计算方法，但讲师说不用了解。
- **GDP 增速**：一定时间内的增长率。讲师提到今年上半年是 5 还是 6（原文未明确具体数值），比以前低，比前两年高。
- **货币购买力**：一定数量的货币在市场上能买到的商品和服务数量。
- **社会融资规模**：中国很重要的指标，指实体经济从资本市场或金融体系融资获得的总量。
- **M2**：中国常用的货币供应量衡量标准，涵盖现金、活期存款、储蓄存款等。还有 M1、M2 剪刀差，属于货币银行学内容，讲师没有展开。
- **PPI（生产物价指数）**：生产企业原材料和商品的价格变化。
- **制造业 PMI**：根据关键经济指标编制的指数，衡量制造业经济活动水平。荣枯线是 50，50 以上表示扩张，50 以下表示萎缩。
- **失业率**：讲师说不用讲。

### 3. 日元零利率和 SDR 是理解国际货币体系的入口

- **日元零利率**：日元长期零利率，几乎没有借贷成本。日本是中国改革开放以来的最大投资国，过去 30 年也是全球很大的投资国，因为国内利率为零，资金只能往外投，投向新兴国家。
- **政策意图与批评**：日本长期零利率本意是刺激消费和经济，但效果有限，很多经济学家批评它。
- **国际使用**：日元完全流通、自由兑换，国际上很多人借日元去做投资，因为几乎没有成本。日元在国际贸易使用中排第三，储备中也有不少人使用。
- **汇率不稳定**：日元虽然重要，但汇率不稳定，受地缘政治、日美两国财政和货币政策等影响。
- **SDR（特别提款权）**：IMF 创造的一种国际货币储备资产，可以理解为一种货币。它没有专门的钞票发行，是一种计量单位，价值取决于一篮子货币。
- **组成与作用**：一篮子货币包括美元、欧元、人民币、日元、英镑。SDR 有国际储备作用，也可用于国际支付。人民币 2016 年加入 SDR，被认为是人民币国际化的重要里程碑。

### 4. 美国是全球最大的金融市场

- **规模支撑**：经济体量和 GDP 最大；有纽约、芝加哥、洛杉矶等重要金融中心；金融产品多元，几乎所有标的在美国都有；美元在很多国家是硬通货。
- **制度支撑**：金融法律和监管比较完善；创新和技术推动了市场发展，电子交易、高频交易和量化祖师爷 Simons 都出自美国；是国际投资者的热门目标。
- **稳定性支撑**：讲师提到美国本土几乎没有战争风险，俄乌战争后大量欧洲资本流向美国；200 多年来内部只打过一场仗。

### 5. 离岸人民币的走势由利差、增长和情绪共同推动

- **离岸人民币**：在离岸市场（通常是香港）交易的人民币，主要对美元。7.32 意思是一美元兑七块三毛二人民币。
- **近一年走势**：课堂中提到的去年 10 月底汇率最低，也就是人民币贬值最厉害的时候，原因是经济预期差、外资出逃；经济复苏后汇率急转直下，加上美国加息步伐渐缓；今年年初市场认为美国加息要在今年停止，汇率大幅下降；大约三月份之后，中国经济复苏不及预期、美国加息好像要重新开始，汇率又往上涨。
- **利率差异**：较高利率会吸引外国投资。美国不断加息，导致美元回流、美元指数上升；中国降息则人民币走弱。
- **经济增长**：经济增长强劲会增加对本国货币的需求。
- **其他因素**：贸易政策（外资恐慌性出逃）、市场情绪（乐观时汇率上升，情绪差时走弱）、国际投资流动、全球金融市场波动。
- **人民币与港股**：结论性说法是汇率严重影响港股市场，人民币一旦走弱，港股一定走弱，这是基本趋势。讲师提到有一份 PDF 会发出来，因为比较长，非金融本科的同学可能不容易看懂。
- **去年欧元和英镑**：较高通胀使货币贬值，较低通胀使货币升值。英国去年有一个大乌龙，准备用央行力量大规模发行国债来应对通胀危机，结果市场认为它的通胀短期内降不下来，同时还在极大扩张杠杆，英镑去年一度跌到七点几，快跟美元差不多，但最终涨回来了。德国和法国则因战争影响经济增长，货币贬值。能源价格（天然气、石油）上涨也导致汇率下跌。
- **美元指数**：美元相对一篮子其他货币的汇率变动指数。影响因素包括美国经济数据、美国货币政策、全球经济环境、地缘政治风险、市场恐慌与投资者风险偏好、全球利率差异。
- **中美利差**：人民币持续走低的一个原因是中美利差大约达到 2%，美国比中国高。如果美国 GDP 增长 3%，中国必须增长 5% 才能平掉这个利差，增长不到 5% 就压不住汇率压力。
- **外汇市场参与者**：央行（稳定汇率时大量投放外国货币买入本国货币）、商业银行和做市商（提供货币兑换，战争等极端情况下可能不允许换汇）、进出口商（频繁结汇换汇）。
- **外汇交易方式与策略**：现货、远期、期权；策略有均值回归、趋势跟随、统计套利、事件驱动，讲师说任何交易都可以套用这类框架。

### 6. 美国股市分四个层级

- **第一级**：纽约证券交易所和纳斯达克，最主要的证券交易所。
- **第二级**：为中小型公司股权服务的市场。
- **第三级**：区域性股票市场。
- **第四级**：OTCBB 板块和粉单市场。
- **粉单市场的例子**：瑞幸咖啡因财务造假从美国退市，后来在粉单市场上市。讲师说自己持有瑞幸咖啡。粉单市场的交易会延迟并受各种限制，但也让这类公司能上市融资，同时向投资者提示风险。

## 七、股票：分析方法与 A 股规则

### 1. 基本面分析和技术分析的分歧，本质是股票是商品还是权益

- **基本面分析**：研究公司的经济指标、行业趋势、财务状况来预测未来价值，巴菲特使用这类方法，关注内在价值和潜在增长。讲师提醒，很多吹票所说的 20% 到 30% 年增长率是瞎掰的。
- **技术分析**：通过历史价格、成交量和图表指标预测价格趋势，关注成交量、价格变动和投资者行为，常用于短期交易和投机。
- **分歧的核心**：股票到底是一种流通的商品，还是一家好公司的权益所有权。如果是商品，价格由市场供需决定，价高者得；如果是权益，价格和成交量不应该大幅影响它的内在价值。
- **讲师的观点**：股票既是权益也是商品，两种属性不互斥。在某些特定情况下它会更多表现出商品性质，例如游资或大户拉升时，大家不管基本面、愿意高价买，价格就上去了。地天板、天地板这类走势无法用基本面解释，只能靠技术分析，因为有人撬板。

### 2. A股的交易规则限制了很多策略

- **T+1**：今天买入的股票今天不能卖。做 T 的做法是昨天买入的份额今天卖掉再买回来，或先买后卖，但卖出的只能是昨天买入的份额。
- **涨跌停**：普通股票 10%，ST 股票 5%，科创板 20%。
- **缺少做空**：A股没有传统意义上的做空，禁止裸空，主要靠融券，而融券通常只提供给大票，冷门股票很难做空。
- **几种特殊走势**：跌停板指跌停后价格就不动了；一线天指开盘直接涨停一直到收盘；地天板、天地板指先跌停再涨停或先涨停再跌停。

### 3. 股票市场是流动性最好、信息最透明的量化场景

- **流动性最好**：买卖股票的人最多，容易买入卖出，适合实施各类量化策略。
- **信息比较公开透明**：基本面数据不算完全透明，但已有越来越多公司以更低价格向个人和机构提供。原文提到很多公司愿意低价提供信息，因为希望提高市场流动性和成交量。
- **市场效率较高**：发生事情后价格能迅速反应。
- **交易成本比较高**。
- **波动性比较好**，交易者偏好这类特征。
- **加密货币的量化交易性质甚至比股票更好**，所以高频交易很多在加密货币上做。

### 4. 基本面因子在下跌行情中失效更快

- **基本面因子**：盈利、负债、现金流等，讲师提到最近这些因子不太起作用，因为 A股整体处于下跌趋势，市场主要由贝塔主导。
- **动态波动率**：原文提到的因子之一。
- **技术指标与情绪因子**：情绪因子通过抓取股吧、雪球等社交媒体上对公司的正负面评价来构造，讲师说这个因子也有效。
- **NLP（自然语言处理）**：一些私募用 NLP 读取社交媒体文本构造情绪因子。
- **传统因子失效加快**：尤其是基本面因子只能作为参考，不能单靠它做策略，这也是不少私募和研究员转向高频的原因。
- **基本面量化的实现方式**：主要用特征工程，把收集到的数据加工成衡量基本面的指标和特征。国内量化私募招基本面量化的人少很多。

## 八、量化行业的机构与岗位

### 1. 降息降准的效果取决于经济周期

- **中央银行**：国家货币政策的制定和执行机构，负责货币供应。央行放水、被戏称"央妈"，因为它的策略影响面很广。
- **美联储**：美国的中央银行。讲师提到美联储的独立性比中国央行强很多，主席的权力也大很多。
- **商业银行**：为个人、家庭和企业提供金融服务。中国四大国有银行是中国银行、农业银行、工商银行、建设银行，在中国金融体系中地位重要，每年利润达到 2000 多亿。
- **降息**：降低基准利率，降低借贷成本，刺激经济活动。但利率降了不代表一定有人借钱，经济预期也会影响，所以降息不一定是利好，利好的程度也不一样。讲师举例说，零几年、一零年左右经济繁荣期搞货币大放水和大基建时猛烈降息效果非常狂野，现在经济有周期性波动，降息效果不同。
- **降准**：降低存款准备金率，银行可放贷的钱变多，也是利好。
- **存贷利差**：银行吸收存款的利息低于放贷的利息，这个差价是银行天然的利润来源，只要钱能放出去就稳赚。
- **虚拟货币做市**：个人可以在虚拟货币市场做做市商，没有牌照，本质上就是自己在执行做市策略。方法是在流动性稀缺时释放流动性，在流动性大、散户多、成交量大时回收流动性。流动性高时价格低，流动性低时价格高。

### 2. FOF 是量化私募的重要资金来源

- **FOF（基金的基金）**：它不直接投股票，而是投资基金。在它这里，九坤、幻方、明宏、嘉熙（原文用词，可能为口误或简称）这类量化私募基金变成了可配置的标的，FOF 在基金之间做资产配置。
- **关系要维护**：很多 FOF 是大买方，会来投资基金，所以私募公司要和 FOF 维护好关系。

### 3. 与量化打交道的机构可以分成三类

- **国际投行与国内券商**：摩根大通、摩根士丹利、高盛等国际投行；国内有"三中一华"以及广发、海通、招商证券、光大等，看研报时会频繁遇到。跨境券商富途和老虎主要做美股和港股，讲师提到这两家最近业务受到一些影响。
- **对冲基金与量化公司**：讲师提到 Renaissance（文艺复兴，被称为量化的祖师爷）、千禧年基金、Two Sigma、Point72、Jane Street（做自营）、Optiver（主要做期权）等。对冲基金（私募投资基金）和量化交易公司有交叉，有些公司两者兼具，有些做对冲或自营但不一定纯用量化。投行也有量化交易自营部门。
- **金融科技公司**：卡方、飞凸这类公司不做量化交易，而是提供算法支撑和解决方案。小公司自己从零搭建交易系统成本高（招一个量化开发一年几十上百万），可以选择买它们一年 50 万或几十万的解决方案。
- **传统机构**：银行、保险跟量化关系不大。证券公司和券商投行负责证券买卖、经纪代理、托管、资产管理，做量化要和券商谈佣金费率。

### 4. 量化团队里研究和开发是两条路

- **量化研究员**：讲师说课程主要面向这类方向。
- **Trader**：基于量化模型和策略执行交易，监督模型的实际运行。
- **PM**：在量化交易中做到比较好之后升上去的职位。
- **开发岗**：负责开发和维护，对 C++ 和代码能力要求特别高。讲师说周五会请一位 ACM 金牌背景的开发者介绍这个岗位，并提到参加课程的大部分人可能不具备做量化开发的资格，主要走研究路线，但可以通过努力到达。

## 九、投资组合理论与公司财务

### 1. 投资组合理论的核心是风险和收益的权衡

- **投资组合**：一个人持有的所有投资。只有现金、活期存款、定期存款也算。凡是希望在未来获得回报、又不是赌博的行为，都构成投资组合的一部分。
- **马克维茨的理论**：讲师提到马克维茨前段时间去世，他的理论具有开拓性。现代投资理论广泛用于资产配置，目标是在期望收益较大、方差较小的组合之间做权衡。
- **夏普比率**：用收益除以收益的标准差，衡量每承担一单位风险能获得的额外回报。夏普比率高说明投资回报相对较高。讲师说评价因子或策略好不好，很多时候就看夏普比率，比单看年化收益或最大回撤更直观。
- **风险与收益并存**：不接受风险只能拿低收益。期望收益低而风险大（如赌博）没有意义。目标是尽可能扩大夏普比率。
- **贝塔系数**：衡量资产或投资组合与整体市场的相关性。贝塔为 1 表示与市场波动一致，大于 1 表示波动更大，小于 1 表示更小。讲师提到很多人赚的是贝塔的钱，却以为赚的是阿尔法；市场变差时阿尔法就消失了。牛市里怎么折腾大概率都赚钱，熊市里用尽浑身解数也可能赚不到钱。
- **有效市场假说**：对量化来说可以当作不存在，因为做量化就意味着认为市场不是高度有效的。如果市场真的高度有效，就不该有那么多噪音和价格波动。假说分弱势、半强势、强势三种。讲师认为美股可能接近半强势，A股可能是一个不怎么有效的市场。
- **市场组合理论**：基本投资理论，讲师说跟量化关系不大。
- **CAPM（资本资产定价模型）**：估计资产预期回报的风险模型。核心思想是资产的预期回报与它的系统性风险成正比，这部分风险无法消除。公式里有 rf（无风险利率）和 βi（系统性风险系数）。对量化来说，CAPM 提供了构建和评估交易策略的理论框架，可以用来评估市场风险和回报、确定投资组合权重；也可以用来构建多因子模型，CAPM 相当于多因子模型中只考虑市场因子的特殊情况。

### 2. 公司财务是基本面量化的原料库

- **三大报表**：资产负债表、利润表、现金流量表。
- **资产负债表**：展示公司在某个特定时间点的资产、负债和所有者权益，满足"资产 = 负债 + 所有者权益"的恒等式。
- **基本面量化的数据来源**：做基本面量化要调用三张表里的参数和数据。在一些量化平台（原文列举的平台名称转写不清，包含"米筐""聚宽"等）做股票阿尔法回测时，会频繁使用三张表的数据。基本面和量价是最基础的两批因子。
- **财务比率分析**：量化分析师常用财务比率评估公司的财务状况和经营绩效，包括盈利能力（如净利润率）、偿债能力（如利息保障比率）、运营效率（如总资产周转率）。
- **盈利因子**：净利率、毛利率、营业利润。
- **财务稳定性因子**：负债水平。负债太高杠杆高、风险大；负债太低则资产利用效率不高，因为靠股东权益投资的成本更高（发新股会引入新投资者参与分红，对原有投资者不利）。所以杠杆率既不能太高也不能太低。
- **流动比率**：反映偿债能力。
- **成长因子**：如营收增长率。讲师以 B站 为例，客户规模和营收一直增长，但一直没赚钱、亏得越来越多，说明因子要结合着用。
- **资本结构分析**：分析公司的融资情况和财务稳定性，看负债比率、杠杆比率、负债和权益谁更多。负债太高有资不抵债的风险，股权比率太高则分红压力大，赚到的钱不能很好地用于再投资。
- **估值因子**：一家一年赚 5000 万的公司，该给十亿、五亿还是三亿的估值，有多种可能。
- **市盈率（PE）**：市值与盈利的比值。讲师说 IPO 一般按 10 到 20 倍估值（行业不特殊的话）。PE 的含义可以粗略理解为公司价值相当于未来多少年的收入。讲师举例科大讯飞涨得猛，大股东减持后当天跌了 8% 或 9%，因为它 PE 达到 60 多倍，估值太高。
- **市净率和市销率**：有些公司不适合用市盈率，需要用市销率。
- **折现现金流（DCF）**：把未来的收入按利率折现，因为今天的一块钱不等于明天的一块钱。
- **市场比较法**：一级市场用得多，二级市场也用。把公司和行业内其他类似公司做估值对比。如果行业内的稳定公司估值 25 倍，这家公司到了 40 倍，除非有业绩爆发、大利好或管理层表现很棒，否则很可能很快跌下来。

## 十、金融衍生品

### 1. 远期、期货、期权是三种基本的衍生品

- **远期**：最简单的金融衍生品，双方约定在未来某一时间按特定价格买卖。
- **期货**：标准化合约，约定未来某一时间以特定价格交割，交割物可以是商品、货币、股票。
- **期权**：授予持有人在未来特定时间以特定价格买入或卖出标的资产的权利，但不是义务。不行权只损失期权费，行权则行使权利。分 call（看涨）和 put（看跌），也分欧式和美式，欧式只能在到期日执行。
- **常见品种**：纽约黄金、布伦特原油、伦敦铜期货、欧洲天然气、生猪期货、比特币永续。
- **比特币永续期货**：上述期货基本都有到期时间，比特币期货是永续的，没有到期日，可以一直持有。比特币永续期货和现货之间的价差套利比较流行。
- **蒙特卡罗模拟**：用随机性数据进行模拟，估计金融产品的风险和收益，也用于期权定价。

### 2. 看涨期权的收益结构不对称

- **权利与义务**：购买者持有在未来以约定价格买入标的的权利。到期前如果市场价格涨过行使价，可以选择行权。
- **例子**：当前价格 100，约定行使价 105，若涨到 110，可以用 105 买入价值 110 的股票，净赚 5 元（未计期权本身的价格）。
- **收益公式**：讲师给出的收益是取 max(ST - X, 0) 再减去期权价格 p，其中 ST 是到期股票价格，X 是行权价。价格低于行权价时选择不行权，收益为零，只损失期权费。看跌期权的收益方向相反，是 X - ST。
- **讲师提醒**：这部分公式讲得比较简略，例子里的收益计算没有算上期权本身的价格。

### 3. 期权价格受到期时间、波动率和利率影响

- **到期日**：临近到期时期权价值下降。因为期权代表未来的可能性，到期日越远，价格向上或向下的空间越大，价值越高。
- **波动性**：波动性越高，期权价格越高。讲师解释，看涨期权当前 80，未来可能涨到 100 也可能跌到 60；跌到 60 只损失期权本身的价值，涨到 100 时期权价格会暴涨，所以向上的收益和向下的损失不对称。
- **标的资产价格**：看涨期权随标的上涨而上涨，看跌期权随标的下跌而增加。
- **利率**：影响合约定价，模拟和计算时要用到无风险利率。
- **股息和收益率**：会降低看涨期权的价值、增加看跌期权的价值。因为发股利会在价格上扣掉，例如股票原来 11 元，发 1 元股利后股价变成 10 元。
- **流动性**：流动性差的市场买卖价差更大，也会影响定价。
- **隐含波动率（implied vol）**：通过 BS model 从市场价格反推出来的波动率水平，用来衡量市场对标的资产未来价格波动的预期。它不是标准的波动率。如果判断出市场未来的波动率和引波有差距，可以做期权交易套利。

### 4. BS model 是衍生品定价的基准工具

- **模型性质**：金融衍生品定价模型，有很多假设，最终假设股票价格服从几何布朗运动，由此得到 call 和 put 的定价公式。
- **课程安排**：讲师说参加刷题的话后面两周会讲到，具体推导比较复杂，课上不推。
- **衍生品在量化中的应用**：可以高速、精确地执行交易，更快响应市场；交易标的增多后不必只做正股，灵活性和流动性更好；期权和期货有看多和看跌两方，可以用来对冲风险；衍生品也有专门的套利策略。
- **基于蒙特卡罗模拟的定价流程**：选择合适的数学模型描述衍生品价格运动（如布朗运动、几何布朗运动），设定参数，构造蒙特卡罗模拟生成随机路径来模拟标的资产价格变化，再用随机过程模拟演化，计算每条路径下的衍生品价格，最后根据衍生品特性算出价格。
- **杠杆属性**：衍生品的价值依赖原生金融产品，这一点不会变。期货只需少量保证金；期权有 Delta，Delta 一般很大，标的变动较少时期权价格就会变动很多。
- **定价的门槛**：期权量化比较复杂。讲师提到 Optiver 主要做期权衍生品量化，国内有龙旗（讲师说龙旗在杭州），门槛比较高，专门做衍生品和专门做股票不一样。

## 十一、量化方法与风险管理

### 1. 量化的本质是把非数量概念变成可度量的模型

- **词源**：量化来自 quantitative 或 quantification，把非数量的性质和概念量化过来，从而精准、可重复地度量和计算。
- **方法基础**：通过数学公式和数学分析的理论模型，主要用数据统计、机器学习、深度学习，把现实问题抽象成数学模型，再用模型做数据分析，主要应用在金融领域。
- **噪音问题**：很多人以前不认为金融市场可以量化，因为噪音太多。讲师的观点是噪音多不代表不能量化，业界多年探索已经积累了很多方法。
- **前提提醒**：量化不一定对、不一定好，跟水平有关，也跟市场有关，不是 100% 正确。

### 2. 因子的边际收益高于模型

- **简单回归够用**：量化公司很多时候用的就是简单回归，不会用很复杂的模型。
- **因子优先**：因子好的话模型不用很好；因子不好的话，模型很难做好，还可能反过来把好因子搞坏。
- **数据流程**：后续课程会教数据获取、清洗和预处理。讲师提到不会用很多开源包，因为用起来不方便。
- **验证与评估**：交叉验证、验证集、样本内和样本外，这些统计分析方法都会用到。
- **时间序列分析**：有用，CTA 会用到，但讲师观察实际使用相对少一些，不是没有。
- **机器学习的作用**：可以替代一部分工作，比如找参数，深度学习可以用来挖因子，弥补人脑思考耗能大、相对低效的问题。
- **机器学习的不足**：受数据质量和偏差限制，容易过拟合，数据清洗不到位结果会很差；黑箱，缺乏可解释性和透明度；缺乏外推性，做出一个模型不代表能做出第二个。
- **学界与业界的认知差异**：讲师提到学界可能觉得机器学习这块根本没法用，业界用得还不少，而且慢慢在增多。

### 3. 风险管理面对的是一个不可能三角

- **不可能三角**：年化收益、最大回撤、管理规模三者不可兼得。追求高年化收益同时又要很小的最大回撤，容量可能只有几千万，上亿都不容易，管理规模很小。
- **做大与收益的取舍**：要做百亿私募，就不能追求过高的年化收益和过低的最大回撤，必须容忍回撤高一点或收益低一点。
- **度量风险的方法**：用历史数据、方差和协方差构建风险模型，计算不同资产之间的方差和协方差；历史模拟法；蒙特卡罗模拟法；风险因子和资产定价。
- **夏普比率的作用**：超额收益（平均年化收益率减去 rf）除以波动率。夏普比率越高，承担单位风险获得的超额收益越多。讲师说评价策略时，与其报年化收益和最大回撤，不如直接给夏普比率。最大回撤很高的话做不出高夏普。夏普比率还有一个好处，可以理解为愿意承担多少风险。
- **卡马比（Calmar）**：一般用年化收益除以最大回撤。它有自己的计算方法，主要用下行标准差或下行波动率。实际运用中可能用最大回撤来模拟。卡马比和夏普比率都是越高越好。
- **对风险的态度**：一定要 take risk，高风险伴随高回报。不能拒绝风险，不能踩风险、不能迎着风险上、不能忽视风险，但风险发生时要想办法利用它。
- **利用风险的例子**：龙旗等做期权量化的机构，在某年春节后开市第一天（原文年份表述含糊，未明确是 2020 年还是 2022 年）A股大跌 8%，据说做期权的赚了上亿。
- **量化交易的优势**：即使方法不好，也比很多主观交易更好，因为会控制风险、控制情绪，行为更理性。
- **核心观点**：风险无法避免，风险本身就是最大的阿尔法。如果不承担风险，就赚不到钱。
- **投机是一生的事业**：讲师引用一位代教老师的话（原文提到"在打折州"，具体所指未明确），说投机是一生的事业。如果觉得投机不好听，可以改成投资，两者在承担风险这一点上是一样的。

## 十二、关键概念

| 概念 | 用大白话讲 | 在本文里起什么作用 |
|---|---|---|
| 一级市场 | 公司第一次把股票、债券卖给公众、拿到钱的地方 | 说明量化交易不在这里，这里只是公司融资 |
| 二级市场 | 已经发行出去的证券在投资者之间转手买卖的地方 | 量化交易的全部战场 |
| 做市商 | 在没人愿意买卖时自己站出来接单，用买卖差价赚钱的角色 | 提供流动性，个人也能做 |
| 滑点 | 下单时看到的价格和实际成交价格的差额 | 低价股上滑点占比大，是量化成本的一部分 |
| 佣金与手续费 | 每笔交易要付给经纪商或平台的钱 | 成本高低直接决定量化策略能否盈利 |
| 可转债 | 一种既能收利息、又能在条件满足时换成公司股票的债券 | 兼具债和期权的性质，有事件驱动和套利策略 |
| 十年期美国国债利率 | 借给美国政府十年的利息水平 | 被视为低风险定价基准，它一涨会挤压其他资产 |
| 联邦基金利率 | 美国银行之间短期借钱的利率，美联储用加息降息来调控 | 影响全球借贷成本，也是"加息"具体加的对象 |
| LIBOR | 伦敦银行之间短期借钱的利率 | 国际基准利率，同业拆借的成本参考 |
| 订单簿（order book） | 实时列出不同价格上想买和想卖各有多少 | 高频策略的微观数据来源，用来看流动性 |
| K 线 | 把一段时间内的开盘、收盘、最高、最低价画成一根柱 | 相对宏观的数据，数据量比订单簿少 |
| 夏普比率 | 每多承担一单位波动，能多拿多少超额收益 | 评价策略好坏的主要指标 |
| 卡马比（Calmar） | 年化收益除以最大回撤 | 另一个评价指标，和夏普一样越高越好 |
| 贝塔 | 一个资产或策略跟整个市场的联动程度 | 区分赚的是市场整体上涨的钱还是策略本身的钱 |
| 阿尔法 | 扣掉市场整体涨跌后，策略自己挣到的那部分收益 | 讲师说风险本身就是最大的阿尔法 |
| CAPM | 认为资产预期回报应该跟它无法分散的那部分风险成正比 | 多因子模型的原型 |
| 有效市场假说 | 认为价格已经反映了所有信息，所以赚不到超额收益 | 做量化的人基本把它当作不成立 |
| SDR | IMF 造出来的一种账面储备资产，价值由几种货币加权决定 | 人民币 2016 年加入，是国际化的一步 |
| 美元指数 | 美元相对一篮子其他货币的强弱 | 判断全球资金流向和汇率压力的参考 |
| 离岸人民币 | 在中国境外（通常香港）交易的人民币，主要对美元 | 观察外资流向和国内经济预期的窗口 |
| 隐含波动率 | 从期权价格反推出来的、市场对未来波动的预期 | 期权定价和套利的核心变量 |
| BS model | 假设股价按几何布朗运动随机走，用来给期权定价的公式 | 衍生品定价的基准工具 |
| 保证金与杠杆 | 只用一小部分钱就能控制大额头寸，亏到一定程度就会被强平 | 期货策略必须上杠杆，最大回撤是生命线 |
| 永续期货 | 没有到期日、可以一直持有的期货 | 比特币特有，衍生出与现货的价差套利 |
| T+1 | 今天买的股票今天不能卖 | A股规则，限制了日内策略 |
| 涨跌停 | 一天内价格最多只能涨跌固定比例 | A股规则，涨停 10%、ST 5%、科创板 20% |
| FOF | 不直接买股票、而是买基金的基金 | 是量化私募的重要资金来源 |
| CTA | 主要做期货等品种、跟随趋势的一类策略 | 可转债的事件驱动策略可以借用它 |
| 另类数据 | 传统财报和行情之外的数据，比如无人机拍的油罐画面 | 期货等品种的信息来源补充 |
